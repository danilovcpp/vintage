# Design review

Use for evaluating UX proposals, mockups or implemented UI, not to silently redesign approved flows. Compare with `playbooks/UX_STANDARD.md`, SRS/PRD and current screen inventory. Inspect hierarchy, consistency, information density, responsive layouts, WCAG targets, keyboard/focus, colors, failure/loading/empty/permission states, text quality and data completeness. Label screenshot-only or text-only assumptions. Return severity-ranked concrete findings, acceptance tests, trade-offs and smallest remediation; if no browser/Figma access, explicitly limit conclusions.
