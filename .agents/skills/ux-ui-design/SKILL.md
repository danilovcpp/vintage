# UX/UI design and design-system handoff

Read `playbooks/UX_STANDARD.md`, PRD, SRS, personas and flows. Ask 3–5 design-specific questions if critical unknowns exist (device, user environment, density, existing brand, accessibility). Do UX analysis first; produce IA, flows, wireframes as Mermaid/text descriptions, screen/state catalog, responsive behavior, component inventory, tokens, a11y and copy strategy.

Make 2–3 alternative patterns only for consequential screens; compare useability vs implementation cost. Use `templates/06_UX_UI.md`. Choose Penpot/Figma/browser prototype by actual enabled tools and owner's preference; if tool absent, produce precise editable handoff specs instead of claiming mockups exist. Validate via representative tasks and owner approval, then hand over to frontend/mobile leads. Include loading/empty/error/permissions/offline states.
